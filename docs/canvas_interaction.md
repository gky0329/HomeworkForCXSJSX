# 画布交互说明

本文档记录代码可视化画布的边界、缩放、平移和图元越界处理方式。

## 画布移动

- 在代码可视化区域按住中键拖动，可以平移整个画布视图。
- 这个动作只改变 `QGraphicsView` 的视口位置，不会修改任何图元的绝对坐标。

## 缩放

- `Ctrl + 滚轮`：缩放视图。
- `Fit to View`：按当前可见图元的真实边界自动缩放到合适大小。

## 当前 fit 逻辑

`Fit to View` 不再使用整张场景的 `sceneRect()`，而是只对当前可见图元计算边界：

- 顶层且可见的图元才参与计算。
- 普通图元使用 `sceneBoundingRect()`。
- 自绘曲线箭头使用自定义的可视边界，包含路径和箭头头部。
- 最终会和场景边界做交集，再加一圈 padding 后执行 `fitInView(...)`。

## 图元越界处理

- 栈图元和堆图元在尺寸变化后会重新计算宽高。
- 每次重算几何时，图元会自动检查自己是否已经超出场景范围。
- 如果发生越界，图元会被夹回场景内，但不会改变内部的绝对布局规则。
- 左键拖动也会被限制在场景范围内，不能把图元拖出画布。

## 尺寸重算规则

- 图元宽度按每一行真实文本宽度计算，而不是按字符数粗估。
- 当变量值变化时，会重新计算图元尺寸，并同步刷新位置约束。
- 这样可以避免长文本把内容挤出图元边框。

## 默认放置与避让策略

- 画布会为每个图元维护一个全局唯一的“布局帧号”。`main` 图元固定为 `0`，且永不避让。
- 新建图元时，画布按帧号从小到大扫描一次：如果较大帧与已有较小帧重叠，就尝试把它放到已有图元的右侧；如果右侧无法容纳，再尝试放到下方。每个图元只尝试一次，不进行循环搜索。
- 尺寸变更时，画布同样按帧号从小到大扫描一次，让较大帧尝试避开较小帧。这样可以保证默认布局不重叠，同时保留手动拖动重叠的自由。
- 手动拖动：用户仍可把图元拖到重叠位置；拖动本身不会触发自动反复重排，也不会回收/重用已经分配过的布局帧号。
- 更新时会优先沿用上一次保存的位置；如果某个图元当前位置没有与其它图元重叠，就不会再被自动挪动回默认位置。
- 避让判定使用的是图元的“边界框”本身，也就是图元框体大小，不会把内部文字或箭头纳入默认避让范围。这样默认避让只保证框与框不重叠，不会因为文字内容或连线箭头把空间撑得过大。
- 首次渲染完成后会自动执行一次 `Fit to View`，方便进入分析页时看到完整初始布局；后续步骤切换与位置更新不再自动 `fit`，只有手动点击 `Fit to View` 才会调整视点。

这些策略的实现位于：
- [app/ui/canvas/memory_canvas.py](../app/ui/canvas/memory_canvas.py) ：`_register_layout_frame()`（分配布局帧号）、`_resolve_layout_once()`（按帧号单次扫描并做默认避让）以及在 `render_state()` / `resize` 回调中的调用。

如需更复杂的布局（例如螺旋搜索、列式堆叠或保护某些关键图元不被移动），可以在该模块中替换避让策略函数。
